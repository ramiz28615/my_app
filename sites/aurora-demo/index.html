Sıkça sorulanlar

Merak ettiklerin,
bir tık uzağında.

Bu örnek site gerçekten GitHub Pages üzerinde mi?

Evet. Sayfa Dimensia Studio’nun açık GitHub deposundaki sites/aurora-demo/index.html dosyasından yayınlanır. Statik hosting için özel sunucu gerekmez.

GitHub Pages gerçek bir ücretsiz alt alan adı verir mi?

GitHub Pages proje sitelerini genellikle kullanici.github.io/depo/ şeklinde barındırır. İstediğin özel alt alan adı için sana ait domain ve DNS kaydı gerekir.

Site üzerindeki fiyatlar gerçek mi?

Hayır. Bu bir etkileşimli tasarım ve yayınlama gösterimidir. Fiyat kartları sadece UI örneğidir.

HTML, CSS ve JavaScript kodunu düzenleyebilir miyim?

Dimensia Studio’daki görsel editör ve kod alanıyla kendi oluşturduğun sitenin kaynaklarını değiştirebilirsin. Yeniden yayınlama GitHub üzerinde mevcut dosyayı günceller.
